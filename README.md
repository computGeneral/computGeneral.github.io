# ComputGeneral 个人主页

基于 Jekyll 和 GitHub Pages 的简洁个人主页模板，适配桌面和手机。

## 修改内容

- `index.md`：自我介绍、项目和联系内容。项目目前是占位内容，填写后可添加真实链接。
- `_config.yml`：站点名称、简介和 GitHub 个人链接。
- `assets/img/computgeneral.svg`：复用 CGI 框架的品牌字标。
- `assets/css/style.scss`：页面颜色、布局和响应式样式。
- `_layouts/default.html`：导航、页面框架和页脚。

## 发布

推送到 `main` 后，GitHub Pages 自动构建并部署。可在仓库 Actions 的 `pages build and deployment` 查看结果。

旧研究笔记与旧资源已从当前网站移除，需要时可从 Git 历史恢复。原主题许可证保留在 `LICENSE`。
